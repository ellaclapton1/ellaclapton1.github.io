  • W3 School, CSS Background Image tutorial - I used this tutorial to help me put the image inside the navigation box instead of having it as the entire background.
  • MDN, CSS Position Tutorial - I used this tutorial for a lot of positioning content, particularly in making the text frame on the homepage.
  • MDN, CSS text orientation tutorial - this allowed me to make the sideways text for the frame.
  • W3 School, HTML Tables tutorial - I used this to help me with the tables in my websites, specifically for organising the text content into sections.
  • W3 School, CSS Grid Layout tutorial - this was significant in creating the column and page layouts, for example it helped me split the page on
  • W3 School, Lists tutorial - I used this tutorial for my ordered, unordered and nested lists.
  • W3 School, id tutorial - I had some difficulty understanding when to use id and when to use class so this resource was helpful.
  • W3 School, CSS Overflow Property tutorial - this was super helpful when I was trying to style the right side column on the homepage and the other pages.
  • W3 School, CSS Margin tutorial - I relied on margins for styling quite a lot, it was really helpful in organising the layout of the content boxes in tables and for the layout of the images.
  • W3 School, HTML Class Attribute tutorial - I used thos tutorial and it was super helpful for areas in which the styling would stay uniform, for example in whole sections or the layout of the writing, moments and objects pages.
  • W3 School, CSS Links tutorial - I used this to change the style of hyperlinked text, for example, underlining when hovered over.
  • W3 School, CSS Units tutorial - this helped me in my decision to use the rem value for some of my text sizes, margins, padding and positioning. Because there were a lot of different components on each page, it was good to keep everything in proportion.
  • Geeks for Geeks Website - sometimes I would crossreference the W3 School tutorials with this site.
  • Claude, Text frame helpI did consult Claude as I found it difficult to find resources that explained exactly how to use different CSS components for this component.
